# iNAS

NAS 의 SMB 공유를 맥에서는 로그인할 때 자동으로 연결하고, 아이폰·아이패드에서는 파일 앱의 위치로 보여 주는 앱입니다.

| | 맥 | 아이폰 · 아이패드 |
|---|---|---|
| 최소 버전 | macOS 26 (Apple Silicon 전용) | iOS · iPadOS 18 |
| 방식 | 로그인·깨어날 때 창 없이 SMB 공유 연결 | 파일 앱 › 둘러보기 › 위치에 서버마다 하나씩 |
| 비밀번호 | 로그인 키체인 | 키체인 (앱과 확장이 같이 씀) |
| 배포 | GitHub 릴리즈 (공증된 dmg · zip, 자동 업데이트) | 직접 빌드해 기기에 설치 |

## 맥

- SMB 서버를 여러 개 등록합니다. "접속하여 공유폴더 불러오기" 로 서버의 공유폴더 목록을 받아 자동으로 연결할 공유폴더를 고릅니다.
- 왼쪽 서버 목록의 점으로 연결 상태를 봅니다(초록: 고른 공유 모두 연결, 주황: 일부만). 서버 화면에서는 공유마다 "● 연결됨" 이 나오고, 아래 **지금 연결** 로 그 서버만 바로 연결합니다.
- **메뉴 막대**: 자동 연결을 맡은 에이전트(앱 안의 `iNASAgent.app`)가 메뉴 막대에 아이콘을 둡니다. **iNAS 열기**, **iNAS 설정…**(본체 설정 창만 띄움), **서버 ›** 서버마다 "지금 연결 (5개 연결됨)", 마지막 기록 한 줄이 나옵니다.
- **설정 (⌘,) › 서버**: 자동 연결은 로그인 항목(`SMAppService` LaunchAgent, `iNASAgent.app`)이 Dock 아이콘 없이 늘 떠서 합니다.
  - **시작 시 자동 연결**: 로그인할 때 고른 공유를 연결합니다. 네트워크가 늦게 잡히면 서버 응답을 잠시 기다립니다.
  - **연결 해제 시 자동 연결**: 잠자기에서 깨어날 때나 네트워크가 바뀔 때 빠진 공유를 다시 연결합니다. 공유가 빠질 때 서버가 응답하지 않으면(끊김) 돌아올 때까지 1분마다(최대 1시간) 다시 시도합니다. 서버가 응답하는데 빠졌으면 직접 꺼낸 것으로 보고 다음 깨어남·네트워크 변경까지 그대로 둡니다.
  - **연결 후 알림 메시지 표시**: 새로 연결했거나 실패한 공유가 있을 때만 알립니다.
  - 아래 **최근 기록** 에 자동 연결 · 연결 해제 감지 · 실패를 시간순으로 보여 줍니다(에이전트와 XPC 로 주고받고, `~/Library/Application Support/com.moimz.iNAS/agent-log.json` 에 최근 100줄).
  - 두 자동 연결을 모두 끄면 로그인 항목도 해제됩니다.
- **설정 (⌘,) › 일반**: 버전과 업데이트.
- **자동 업데이트**: Sparkle 이 하루 한 번 확인합니다. 메뉴 › 업데이트 확인… 으로 직접 확인할 수도 있습니다.
- **도움말 메뉴**: iNAS GitHub 페이지 · 문제 신고…(새 이슈에 앱 · macOS 버전만 미리 채움).

설치: [릴리즈](https://github.com/moimz/iNAS/releases/latest) 에서 dmg 를 받아 iNAS 를 응용 프로그램 폴더로 옮기고 한 번 실행합니다. 처음 실행할 때 알림과 로그인 항목을 허용해 주세요.

## 아이폰 · 아이패드 (2.2 부터)

파일 제공 확장(File Provider)으로 NAS 를 파일 앱에 붙입니다. iOS 기본 SMB 연결과 달리 **원하는 포트**를 쓸 수 있습니다. 서버별로 공유를 골라 보여 줍니다.

### 파일 앱에서 되는 것
- 서버마다 위치가 하나씩 생깁니다. 위치 이름은 서버 이름이고, 고른 공유만 그 아래에 보입니다.
- **둘러보기**: 공유 날짜는 NAS 에서 읽어 옵니다.
- **내려받기**: 원형 진행과 남은 용량이 표시됩니다.
- **올리기**: 다른 위치에서 NAS 로 복사합니다.
- **정리**: 폴더 만들기, 이름 바꾸기, 지우기가 됩니다(한글 이름 포함, 맥과 같은 NFC 로 저장).
- **NAS 쪽 변경 반영**: 맥 등 다른 곳에서 바꾼 것이 보고 있는 폴더에 10초 안에 반영됩니다.
- **다른 앱에서 쓰기**: Safari 등의 파일 선택 창에서도 NAS 파일을 고를 수 있습니다.

### 썸네일
NAS 의 사진·동영상 썸네일을 iNAS 가 직접 만들어 파일 앱에 넘겨줍니다. 파일 전체를 받지 않고 필요한 부분만 읽습니다.

- 시놀로지가 만들어 둔 썸네일(`@eaDir`)이 있으면 그것을 씁니다.
- 사진(30MB 이하)은 받아서 줄입니다.
- 동영상은 영상의 10% 지점(최대 2분)에서 장면을 뽑고, 검은 화면이면 조금 뒤로 갑니다.
  - mp4 · mov: AVFoundation 이 필요한 위치만 SMB 로 읽습니다. 영상 정보가 파일 뒤쪽에 있어도 됩니다.
  - mkv · avi · wmv 등: 아이폰이 직접 못 여는 형식은 앱에 넣은 FFmpeg(LGPL, 디코더만)로 뽑습니다.
- 만든 썸네일은 앱 캐시에 두고 다시 씁니다.

### iNAS 앱 화면
- **서버**: 추가·편집합니다. 왼쪽으로 밀면 서버를 지울 수 있습니다.
- **받아 둔 파일**: 파일 앱에서 받아 둔 파일의 크기를 보여 주고, "받아 둔 파일 비우기" 로 모든 서버의 것을 한꺼번에 비웁니다(NAS 원본은 그대로, 다시 열면 다시 받음).
- **썸네일 캐시**: 크기를 보여 주고, "캐시 지우기" 로 비웁니다.
- **썸네일 실패 기록**: 썸네일을 만들지 못한 최근 10개를 보여 줍니다. 파일 이름, 이유, 서버, 폴더, 시간이 나오고 "기록 지우기" 로 지웁니다.
- 화면 아래에 버전과 빌드 번호가 나옵니다.

### 설치 (직접 빌드)
1. Xcode 에서 `iNAS.xcodeproj` 를 엽니다.
2. FFmpeg 를 한 번 빌드합니다. `Vendor/` 는 git 에 들어 있지 않습니다.

   ```bash
   Scripts/build-ffmpeg-ios.sh
   ```

3. `iNAS-iOS` 스킴으로 기기에 설치합니다. App Group `group.com.moimz.iNAS` 와 키체인 공유를 쓰는 팀 서명이 필요합니다.

## 소스 구성

| 폴더 | 내용 |
|---|---|
| `iNAS/` | 맥 앱 (SwiftUI, NetFS 로 연결, Sparkle) |
| `iOS/App` | 아이폰·아이패드 앱 (서버 목록·편집, 썸네일 캐시·실패 기록) |
| `iOS/FileProvider` | 파일 제공 확장 (SMB 는 AMSMB2, 썸네일, FFmpeg 연결 `VideoFrame.swift`) |
| `iOS/FileProviderUI` | 로그인 실패 때 파일 앱 안에 뜨는 안내 화면 |
| `iOS/Shared` | 앱과 확장이 같이 쓰는 서버 저장·키체인·썸네일 캐시·실패 기록 |
| `Scripts/build-ffmpeg-ios.sh` | 썸네일용 최소 FFmpeg 빌드 (ffmpeg.org 8.0, LGPL) |

## 라이선스 고지
- [AMSMB2](https://github.com/amosavian/AMSMB2) (LGPL-2.1), libsmb2 포함
- [FFmpeg](https://ffmpeg.org) 8.0 (LGPL-2.1). GPL 구성 요소와 네트워크 기능은 빼고 빌드했습니다. 빌드 스크립트로 같은 라이브러리를 다시 만들 수 있습니다.
- [Sparkle](https://sparkle-project.org) (MIT, 맥)
